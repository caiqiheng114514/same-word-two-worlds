# 同词异义 · 港陆词语小游戏

> 同一个词，香港和内地可以是两个意思。
> 一个小游戏，练「说到不确定的词，敢停下来问一句」。

纯静态站点：`index.html` + `words.js` + `app.js` + `style.css`，无依赖、无构建、无后端。双击 `index.html` 就能玩，也能直接挂在 GitHub Pages 上。

---

## 入口

打开先是**封面**（全屏，天星小轮 · 维港），主按钮直接进情景对话；另外三个是支线。

| 入口 | 是什么 |
|---|---|
| **情景对话 · 8 幕**（主） | 全屏视觉小说：小明来香港找阿伟玩一天，八幕里踩八个词。背景随场景切换，**只显示正在说话的人**（左下角、小尺寸），选项长在对话框里。 |
| **练习 · 24 题** | 5 关由易到难，答错可「再试一次 / 看提醒」，本机记错词 |
| **展示 · 3 题** | 每题一屏，先让大家猜 10 秒，点「揭晓答案」出答案和那句「为什么」 |
| **词条库 · 67 条** | 67 条差异词条，按 A–E 分类，可搜索 |

> 词条库原话：「游戏只占三到五分钟。三题足够，不要贪多；每题揭晓后留一句话的时间，那句话才是观众会记住的部分。」展示模式就是按这句做的。

## 情景对话怎么玩

全屏 ADV（视觉小说）：

- **背景**：8 幕各一张，切幕淡入淡出；宽屏时锁 16:9 居中，两侧留黑，像正经 galgame。
- **人物**：**只显示正在说话的那一个人**——固定左下角，高度 46%，不遮挡主体画面；旁白时不出人；没有半透明挡板，切换时只做一次登场位移。
- **对话框**：底部米白框 + 墨线 + 名牌；文字逐字打出，点 ▼ 补完再翻页（回车/空格同理）。
- **回溯**：对话框**左下角**的「回溯」按钮，退回上一个情节，可反复往回走（最多 60 步）。默契值、连对、已记录的词都会一起退回——所以在选项后回溯再重选，分数不会重复累加。键盘 Backspace / ← 同效。
- **选项**：就长在对话框内部，不是浮在画面上的弹窗。选完先给选项定色，520ms 后再出判定。
- **判定**：人物原地换表情（高兴／疑惑），旁边弹一枚徽章「✓ 接住了 +8」或「! 没听懂 −6」，框内下面一行写清「为什么」。

### 默契值（原来叫「学习热值」）

两个人越聊越懂，比「热值」更贴主题。

- 起始 **20**，范围 0–100，四档：**生疏 / 有点熟 / 熟络 / 老友**
- 答对 **+8**；连续答对再有加成，第二连 +2、第三连起 +4（上限 +12）
- 答错 **−6**，连对清零（回到 +8）
- 数值变化会在右上角飘一下 `+8` / `−6`，升档时仪表轻震一下
- 结局按最终默契分四段文案，并在下面列出八个词「接住了 / 踩了一下」+ 纠正
- **结算 CG**：四档默契各一张——生疏（港铁站冷灰）/ 有点熟（茶餐厅中灰）/ 熟络（街口暖米）/ 老友（维港暖金）。人物与背景同一套双色调 + 同一层网点，跑 `python tools/make-end-cg.py` 重新生成

### 改剧情 / 改画

剧本在 `story.js`（手改）：

```js
{ scene: '第一幕 · 早上 11:00｜旺角街口', bg: 'street-out' },   // bg 指定用哪张背景
{ who: 'aw', text: '我住地下。' },                              // aw 阿伟 / mh 小明 / narr 旁白
{ who: 'mh', text: '…', expr: { aw: 'happy' } },               // 可选：临时指定表情
{ choice: { word, ask, options: [{ text, ok }], ok, bad, fix } }
```

默契参数也在文件头：`start: 20, gain: 8, lose: -6`。

## 词条库怎么更新

词条库来自《香港内地用语差异词条库（互动游戏用）.docx》（第一组，67 条）。**两层数据分开管**：

```
《…词条库….docx》                 ← 原始文档，动它才需要重跑第一行
        │  python tools/docx-to-kb.py "路径.docx"
        ▼
data/kb.pipe.txt   67 条   cat|word|hk|ml|why|format
data/demo.pipe.txt 10 题   n|stem|answer|reveal
        │  node tools/kb-to-js.mjs
        ▼
      kb.js         ← 自动生成，勿手改
```

- 只想改字面（错字、补充说明）→ 直接改 `data/kb.pipe.txt`，再跑一次 `kb-to-js`，不用碰 docx
- 文档里加了新词条 → 重跑 `docx-to-kb.py` 会覆盖 `kb.pipe.txt`，**手改过的字要重来**，所以改字建议在 docx 里改
- 展示模式默认取第 `1、4、9` 题（热身 / 主力 / 收尾），改 `tools/kb-to-js.mjs` 顶部的 `DEMO_PICK` 即可

五类（A–E）和各自的使用建议：

| 类 | 名称 | 条数 | 出题建议（词条库原话） |
|---|---|---|---|
| A | 同词异指 | 21 | 出题首选：两边都在用，答错的人不会觉得自己在猜 |
| B | 一边有 | 16 | 补充题或加分题：重点在揭晓后解释「为什么会有这个词」 |
| C | 禁忌委婉 | 12 | 冲击力最强但要慎用：只说词义，不让观众现场编 |
| D | 称谓 | 8 | 适合角色扮演：叫法一错，对方表情立刻变 |
| E | 校园日常 | 10 | 难度低，适合热身或抢答，不适合压轴 |

## 发布到 GitHub

仓库名：**`same-word-two-worlds`**

### 路线 A：用 token 一键发布（不用装 git）

```bash
set GITHUB_TOKEN=ghp_你的token
node tools/publish.mjs
```

建仓库 → 一次提交全部文件 → 开启 GitHub Pages → 打印站点地址。token 用 fine-grained PAT，勾 `Contents: Read and write` + `Pages: Read and write`，用完即删。

### 路线 B：网页上传（完全不碰 token）

1. **New repository**，名字 `same-word-two-worlds`，**不要**勾 Add a README
2. 进入空仓库 → **uploading an existing file** → 把 `index.html`、`style.css`、`app.js`、`words.js`、`README.md`、`data/`、`tools/`、`docs/` 拖进去 → Commit
3. **Settings → Pages** → Source 选 `Deploy from a branch` → `main` / `/ (root)` → Save
4. 等 30–60 秒：`https://<用户名>.github.io/same-word-two-worlds/`
